# 디스클로저 절차

proofgap은 살아 있는 취약 컨트랙트를 찾을 수 있다. 이 문서는 탐지 이후 무엇을, 누구에게, 언제 알리는지를 정한다.

## 원칙

- 메인넷에서 자금을 움직이는 트랜잭션은 절대 보내지 않는다. 화이트햇 구조가 필요하면 [SEAL 911](https://github.com/security-alliance/seal-911) 같은 전문 조직에 넘긴다.
- 자산이 묶인 건은 비공개 제보가 먼저다. 개별 주소는 조치가 끝나거나 유예 기간이 지난 뒤에만 공개한다.
- 제보에는 결함의 근거(검증키 상수)와 조치 방법만 담는다. 위조 증명을 만드는 방법이나 코드는 담지 않는다.
- 공개 통계는 집계 수치만 담는다.
- 탐지·노출·트리아지 결과는 `data/`에만 두고 커밋하지 않는다. 커밋 메시지, PR 본문, 이슈에도 미공개 건의 주소·이름·개수를 쓰지 않는다.

## 트리아지 기준

`proofgap triage`가 탐지 결과(`data/results/`)와 노출 확인 결과(`data/exposure/`)를 합쳐 우선순위를 매긴다.

| 우선순위 | 조건 | 조치 |
| --- | --- | --- |
| P0 | 자산 있음 (호출자 잔고 $100 이상) | 즉시 비공개 제보. 운영자에게 연락이 닿지 않으면 SEAL 911에 넘김 |
| P1 | 자산은 미미하지만 운영 중인 호출자가 있음 | 비공개 제보는 선택. 하지 않으면 `wontfix`로 기록하고 개별 주소는 계속 비공개 |
| P2 | 자산 없음, 또는 호출자 없음 | 배포자에게 알릴 수 있으면 알림. 집계 통계에 포함 |
| 공개된 사고 | Veil, Foom처럼 이미 공개 분석이 나온 건 | 제보하지 않음. 집계 통계에 포함 |

"호출자 없음"은 호출자가 없다는 증명이 아니다. Base는 바이트코드 참조 검색을 할 수 없고, 다른 배포자가 스토리지에 넣은 참조는 어느 체인에서도 못 찾는다. 공개 전에 다시 확인한다.

## 연락처 찾기

순서대로 찾고, 찾은 경로를 트리아지 기록에 남긴다.

1. 검증기·호출자 소스의 `@custom:security-contact` 주석
2. 프로젝트 웹사이트의 `/.well-known/security.txt`, 저장소의 `SECURITY.md`
3. 버그 바운티 프로그램 (Immunefi 등)
4. 프로젝트의 공식 채널 (문서에 적힌 보안 연락 경로를 우선)
5. 위 경로가 없거나 응답이 없으면 SEAL 911

제보를 실제로 보내는 일은 사람이 한다. 도구는 초안만 만든다.

## 제보 내용

`proofgap triage draft`가 `data/triage/drafts/`에 초안을 만든다. 초안에 들어가는 것:

- 체인, 검증기 주소, 템플릿, 걸린 규칙
- 검증키의 γ와 δ 좌표 (γ == δ == G2 생성원임을 운영자가 직접 확인할 수 있도록)
- 결함의 의미: Phase 2 기여 없이 만든 검증키라서 검증기가 증명의 건전성을 보장하지 못함
- 이 검증기를 믿는 컨트랙트, 잔고 스냅샷, 정지·업그레이드·검증기 교체 수단
- 권장 조치: 운영 중지 또는 입금 차단, Phase 2 세레모니(기여 1회 이상 + 비컨)를 거친 검증키로 검증기 재배포, 호출자의 검증기 교체
- 참고 자료 (공개된 사고 분석)

## 유예와 공개

- 유예 기간은 첫 제보일로부터 90일이다. 운영자가 조치를 끝냈다고 확인하면 그 전에 공개할 수 있다.
- 운영자가 연장을 요청하면 협의한다. 자산이 계속 노출된 상태라면 연장 대신 SEAL 911과 상의한다.
- 공개할 때는 조치 결과를 함께 적는다. 공격 절차는 공개하지 않는다.

## 기록

트리아지 기록(`data/triage/<체인>.json`)의 `status`는 사람이 갱신한다.

| status | 뜻 |
| --- | --- |
| new | 아직 아무 조치도 안 함 |
| contact-found | 연락처 확인 |
| reported | 제보함 (날짜 기록) |
| acknowledged | 운영자가 수신 확인 |
| fixed | 조치 완료 확인 |
| public | 개별 공개함 |
| wontfix | 운영자가 조치하지 않기로 함, 또는 연락 불가 |
